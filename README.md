# Idleon Builds

Standalone browser calculators and optimizers for Legends of Idleon. Open `index.html` through a local static server to access the calculator index.

The All Stats Dashboard provides map-aware character/account breakdowns, normal-map combat outcomes, Divinity rates, Printer Sample Size, and category-specific Carry Capacity. Specialized allocation and simulation workflows remain in their dedicated calculators.

The Research Shape Optimizer includes Res EXP, Minehead, DR, Daily, Class EXP, Insight, Lumi/hr, Jelly operations, Sushi income, Artifact hunting, Megacrop farming, Gaming, Construction, Cooking Mastery, Equinox, and Daily Worship presets. Class EXP and Insight rank their direct shared-pool nodes by purchased bonus; Lumi/hr ranks Missionary and Lil' Baby Menagerie by their relative Lumi gains, including the save-backed additive pool. Activity presets prioritize damage before Bloodcells for Jelly, Bucks before Better Button for Sushi, The Maw then Transcendent Artifacts then Better Button for artifact hunting, Stickery Crowns before Sticker Depot for megacrops, bits before King Tokens for Gaming, and Tiny Cog tier chance before Flaggy Rate for Construction. Daily Worship targets the first All Quick reward multiplier, not additional uses. These are strict node-priority presets, not globally optimal layouts for each activity. Shapes do not increase raw-level mission slots, daily attempts, or magnifier counts. Custom presets remain editable and unchanged. Regression checks: `node js\tests\test-shape-presets.mjs` and `node js\tests\test-shape-priorities.mjs`.

`shadow.html` uses the shared Google sign-in/save loader and shows only a large YES, NO, or UNKNOWN from the saved multiplayer restriction flag (`OptLacc[26]`: zero is unrestricted, nonzero is restricted). Before loading or with missing or invalid flags, it shows UNKNOWN rather than NO; this checks the saved flag, not independent server-side moderation. Regression check: `node js\tests\test-shadowban-check.mjs`.
