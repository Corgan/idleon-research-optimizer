Mechanics overrides

Disable a mechanic (Off), replace it with a value (Set), or multiply its saved value (Scale). These overrides belong to this loadout and follow it into detailed runs and bulk comparisons; Scale resolves separately on each map. Saved values use the selected character and map. The shared Daily guaranteed crystals simulator option takes priority over this list.

Component terms

The individual sources that combine into Drop Rate, Coin Multiplier, Monster EXP, damage, accuracy, multikill and the other combat stats, for the selected character and map. Off makes a source neutral (0, or ×1 for multipliers), Set replaces it and Scale multiplies it; the stat formulas are otherwise unchanged, so an edit flows through every stat that uses that source. Mechanics overrides that replace a final input take priority.
